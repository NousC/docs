The OpenNous MCP server gives an agent the same graph as the [REST API](/public-api/introduction), as thirteen tools.

## Connect

### Hosted

Streamable HTTP at `https://mcp.opennous.cloud/mcp`. Send a workspace API key from **Settings → API keys** as a Bearer header.

```json
{
  "mcpServers": {
    "opennous": {
      "url": "https://mcp.opennous.cloud/mcp",
      "headers": { "Authorization": "Bearer YOUR_API_KEY" }
    }
  }
}
```

A client that can only take a URL can pass the key as `https://mcp.opennous.cloud/mcp?key=YOUR_API_KEY`. The key can end up in logs, so prefer the header.

### Local (stdio)

Run the `@opennous/mcp` package.

```json
{
  "mcpServers": {
    "opennous": { "command": "npx", "args": ["-y", "@opennous/mcp"] }
  }
}
```

The server reads the key from `NOUS_API_KEY`, or from `~/.nous/config.json`, which `npx @opennous/cli login` writes.

| Variable | Default | Purpose |
|---|---|---|
| `NOUS_API_KEY` | none | Workspace API key. Overrides the config file. |
| `NOUS_CONFIG_DIR` | `~/.nous` | Where to look for `config.json`. |
| `NOUS_API_URL` | `https://api.opennous.cloud` | API base URL. Set it for a self-hosted instance. |

### Claude Code

The OpenNous plugin bundles this server with the skills that use it.

```
/plugin marketplace add NousC/revenue-plugin
/plugin install opennous@opennous
```

Or add the server alone.

<CodeGroup>

```bash Hosted
claude mcp add --transport http opennous https://mcp.opennous.cloud/mcp \
  --header "Authorization: Bearer YOUR_API_KEY"
```

```bash Local
claude mcp add opennous -- npx -y @opennous/mcp
```

</CodeGroup>

## First call

Call [`whoami`](/mcp/tools/whoami) first. It confirms the workspace, who the key acts as, whether the workspace is set up, and the plan with ops and credits left.

## Tools

| Tool | Does | REST |
|---|---|---|
| [`whoami`](/mcp/tools/whoami) | Who the key acts as, setup, and budget left | `GET /v2/workspace/whoami` |
| [`find`](/mcp/tools/find) | List people, accounts, or deals by filter | `GET /v2/people`, `/v2/accounts`, `/v2/deals` |
| [`get_context`](/mcp/tools/get-context) | Ranked context on a person, account, or deal | `POST /v2/context` |
| [`query`](/mcp/tools/query) | Activity and facts across accounts | `POST /v2/query` |
| [`attention`](/mcp/tools/attention) | What to work next | `GET /v2/attention` |
| [`get_insights`](/mcp/tools/get-insights) | What customers said, by lane and subtype | `GET /v2/insights` |
| [`add_note`](/mcp/tools/add-note) | Keep a note on a person or company | `POST /v2/notes` |
| [`enrich`](/mcp/tools/enrich) | Enrich one person | `POST /v2/people/:id/enrich` |
| [`score`](/mcp/tools/score) | Score leads against the ICP | `POST /v2/score` |
| [`read_brain`](/mcp/tools/read-brain) | Read or search the GTM brain | `GET /v2/brain` |
| [`write_brain`](/mcp/tools/write-brain) | Save a GTM brain page | `PUT /v2/brain/page` |
| [`set_icp`](/mcp/tools/set-icp) | Set or replace the ICP | `PUT /v2/icp` |
| [`webhooks`](/mcp/tools/webhooks) | Push events to your own stack | `/v2/webhooks` |

Older tools stay registered for existing plugin installs. They are not documented and will be retired.
