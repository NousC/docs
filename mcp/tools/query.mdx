---
title: "query"
description: "Activity and facts across many accounts."
---

Nous retrieves and compacts. Your agent finds the pattern.

| Name | Type | Required | Description |
|---|---|---|---|
| `scope` | object | yes | What to retrieve. See below. |
| `without` | object | | Subtract accounts matching this scope. Same fields as `scope`. |
| `return` | string | | `observations` (default) or `entities`, one row per account |
| `question` | string | | What you want to learn. Enables semantic ranking. |

| `scope` field | Description |
|---|---|
| `kind` | `event` or `state` |
| `property` | Prefix, for example `interaction.email` or `interaction.meeting_scheduled` |
| `source` | For example `gmail`, `linkedin` |
| `entity_id` | One person or company |
| `since_days` | Last N days. Looks back only. |
| `from`, `to` | ISO bounds. Use for future meetings. |
| `order` | `desc` (default) or `asc` |
| `limit` | Default 50, max 200 |
| `facts` | Search durable facts instead of activity. Needs `question`. |
| `reporting` | `role` or `company`. Objections and themes for a seat. |
| `role` | With `reporting: role`, the seat |
| `attention` | `mine`. Your worklist. |
| `foundation` | `icp`. The ICP document itself. |

Examples.

- Emailed in 5 days with no reply. `scope` on `interaction.email_sent` with `since_days: 5`, `without` on `interaction.email_replied` with `since_days: 5`, `return: "entities"`.
- Funnel by stage. `scope: { kind: "state", property: "pipeline_stage" }`.
- Which accounts want to replace Clay. `scope: { facts: true }`, `question: "want to replace Clay"`, `return: "entities"`.

REST: [`POST /v2/query`](/public-api/query)
