---
title: "get_account"
description: "The full record for a person or company."
---

Facts, attributes with confidence and freshness, saved documents, the buying committee, ICP fit, the latest call score, and activity ranked by how much it tells you. For a block shaped to one task, use [`get_context`](/mcp/tools/get-context).

| Name | Type | Required | Description |
|---|---|---|---|
| `id` | string | yes | Email, LinkedIn URL, domain, or entity UUID |
| `intent` | string | | `account_review` (default), `meeting_prep`, `call_prep`, `follow_up`, `draft_email`. Shapes how much history comes back. |

```
person · 9b2f6c1e-4d3a-4f7e-9a51-2c8d7e3b1f40

ICP FIT: 82/100 — strong fit  (VP-level buyer, 200-500 employees, B2B SaaS)

FACTS (9 — durable memory about them):
  [Budget] Budget approved for Q4, owned by the CRO.  (6d ago)
      Sarah Chen · "We have the budget signed off for Q4."
      2026-09-24

WHAT HAPPENED (12 most telling):
  Replied to email · gmail · 6d ago
      Thursday works. Can you bring pricing for 40 seats?
```

When the identifier matches several records, the tool lists the candidates. Call again with one `entity_id`.

REST: [`GET /v2/accounts/:id`](/public-api/accounts)
