---
title: "list_people"
description: "List and filter people in the workspace."
---

People the workspace has engaged. They replied, met, are in the CRM, or were added by hand. Same filters as [`GET /v2/people`](/public-api/people/list).

| Name | Type | Description |
|---|---|---|
| `search` | string | Substring match on email, name, company, LinkedIn URL |
| `pipeline_stage` | string | Exact stage, for example `interested`. Stages are listed on [`GET /v2/people`](/public-api/people/list). |
| `source` | string | Exact source |
| `status` | string | Exact status |
| `email` | string | Exact email |
| `linkedin_url` | string | Exact LinkedIn URL |
| `has_email` | boolean | With or without an email |
| `has_linkedin` | boolean | With or without a LinkedIn URL |
| `icp_fit` | boolean | ICP fits only, or non-fits only |
| `min_icp_score` | number | Minimum ICP score, 0 to 100 |
| `last_activity_after` | string | Active within, for example `7d` |
| `last_activity_before` | string | Quiet for at least, for example `30d` |
| `sort` | string | `last_activity`, `last_activity_asc`, `icp_score`, `icp_score_asc`, `recently_added` |
| `limit` | number | Page size, default 100, max 1000 |
| `offset` | number | Rows to skip |

Returns one entry per person with name, title, company, id, email, LinkedIn URL, stage, ICP score, and last activity. Page with `offset` while more are available.

```
2 people · more available, page with offset
• Sarah Chen — VP Sales at Acme  [9b2f6c1e-4d3a-4f7e-9a51-2c8d7e3b1f40]
    sarah@acme.com · https://www.linkedin.com/in/sarahchen
    stage interested · ICP 82 fit · last activity 6d ago
```
