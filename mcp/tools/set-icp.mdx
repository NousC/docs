---
title: "set_icp"
description: "Set or replace the workspace ICP."
---

Pass the full ICP as markdown. Who the buyer is, who is not a fit, and the scoring rules.

| Name | Type | Required | Description |
|---|---|---|---|
| `body_md` | string | yes | The ICP as markdown |

The ICP text is replaced and versioned. The scoring model is built from it only when the workspace has none yet. An existing model is kept, so weights trained on closed deals survive a text edit. The result says which happened.

Read the current ICP first with [`query`](/mcp/tools/query) `{ scope: { foundation: "icp" } }` and keep what is still true.

REST: [`PUT /v2/icp`](/public-api/icp/update). To train the model on won and lost deals, use [`POST /v2/icp/closed-deals`](/public-api/icp/train).
