---
title: "Get context"
openapi: "POST /v2/context"
---

Ranked context on one person or company, shaped for the task you name and cut to a token budget.

| `intent` | Use it before |
|---|---|
| `account_review` | Reviewing where an account stands. The default. |
| `draft_email` | Writing a first email. |
| `follow_up` | Following up after silence. |
| `meeting_prep` | A meeting. Adds the next and last meeting with attendees. |
| `call_prep` | A call. Same as `meeting_prep`. |

A claim with only `property` and `value` is observed, current, and confident. Claims carry `confidence`, `freshness`, or `basis` only when something is off.
