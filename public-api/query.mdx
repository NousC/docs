---
title: "Query"
openapi: "POST /v2/query"
---

Retrieves activity or facts across many accounts. OpenNous retrieves and compacts. Your agent finds the pattern.

| Want | Send |
|---|---|
| One row per account | `return: "entities"` |
| Emailed but no reply | `scope` on `interaction.email_sent`, `without` on `interaction.email_replied`, same `since_days` |
| Funnel by stage | `scope: { kind: "state", property: "pipeline_stage" }` and read `rollups.by_value` |
| Meetings this week | `scope: { property: "interaction.meeting_scheduled", from, to, order: "asc" }` |
| Facts across accounts | `scope: { facts: true }` plus a `question` |
| Your worklist | `scope: { attention: "mine" }` |
| Objections and themes for a seat | `scope: { reporting: "role", role: "account_executive" }` |
| The ICP document | `scope: { foundation: "icp" }` |

`since_days` only looks back. Use `from` and `to` for future-dated meetings.
