---
title: "List Triggers"
api: "GET https://api.opennous.cloud/api/triggers"
description: "List every trigger subscription in the workspace, plus the catalog of available event types."
---

```bash
curl https://api.opennous.cloud/api/triggers \
  -H 'Authorization: Bearer YOUR_API_KEY'
```

## Response

```json
{
  "triggers": [
    {
      "id": "trg_...",
      "workspace_id": "ws_...",
      "name": "n8n — chase positive replies",
      "url": "https://hooks.n8n.cloud/abc...",
      "events": ["interaction.email_received"],
      "active": true,
      "created_at": "2026-05-27T11:01:00Z",
      "updated_at": "2026-05-27T11:01:00Z"
    }
  ],
  "available_events": [
    "interaction.email_received",
    "interaction.email_bounced",
    "interaction.linkedin_connection_accepted",
    "interaction.linkedin_message_received",
    "interaction.meeting_scheduled",
    "interaction.meeting_held"
  ]
}
```

The `signing_secret` is never returned on read. It's shown only once at create time; rotate via [PATCH](/public-api/triggers/update) if you lose it.
