---
title: "List people"
openapi: "GET /v2/people"
---

People are created by activity from your connected tools, so this group is read-only.

By default the list holds the people your workspace has engaged. Add `include=all` for everyone, cold leads included.

```bash
curl "https://api.opennous.cloud/v2/people?pipeline_stage=interested&last_activity_after=7d&sort=icp_score" \
  -H "Authorization: Bearer $NOUS_API_KEY"
```

This list keeps its own page size, default 100 and max 1000. With `include=all` it follows the usual 50 and 200.

`pipeline_stage` takes a [standard stage](/public-api/deals/pipelines).
