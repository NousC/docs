---
title: "List people"
openapi: "GET /v2/people"
---

Filtered, paginated list of people. Unknown query parameters return `400`, so a filter is never silently dropped.

```bash
curl "https://api.opennous.cloud/v2/people?pipeline_stage=interested&last_activity_after=7d&sort=icp_score&limit=50" \
  -H "Authorization: Bearer $NOUS_API_KEY"
```

## Pipeline stages

| Stage | Meaning |
|---|---|
| `identified` | Nothing has happened yet. The default. |
| `connected` | They did something. Accepted, replied, opened, visited. |
| `interested` | They replied positively. |
| `meeting_booked` | A meeting is on the calendar. |
| `discovery` | A first call happened. |
| `demo` | A demo happened. |
| `negotiation` | Terms or a proposal are on the table. |
| `closed_won` | Signed. |
| `closed_lost` | Lost the deal. |
| `disqualified` | Not a fit, or asked us to stop. |
| `churned` | A former customer who left. |

Page with `limit` and `offset`, and stop when `has_more` is `false`.
