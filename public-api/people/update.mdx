---
title: "Update a person"
openapi: "PATCH /v2/people/{id}"
---

Sets facts and attaches identifiers on an existing person. Only the fields you send change. Asserted facts are sticky, so later activity does not overwrite them.

```bash
curl -X PATCH https://api.opennous.cloud/v2/people/sarah@acme.com \
  -H "Authorization: Bearer $NOUS_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"pipeline_stage": "meeting_booked"}'
```
