## 1. Get an instance

<Tabs>
  <Tab title="Cloud">
    Sign up at [app.opennous.cloud](https://app.opennous.cloud). Nothing to install.
  </Tab>
  <Tab title="Self-host">
    {/* verify against GET-756 */}

    On a Linux server with Docker:

    ```bash
    git clone https://github.com/NousC/opennous.git && cd opennous
    node scripts/selfhost-keys.mjs
    docker compose -f docker-compose.selfhost.yaml up -d
    ```

    Set your domains and `ANTHROPIC_API_KEY` in the env file before you start. The full guide is [Docker Compose](/installation/docker-compose).
  </Tab>
</Tabs>

## 2. Connect your agent

```bash
npx @opennous/cli@latest init
```

This signs you in, saves a key to `~/.nous/config.json` and registers the MCP server with your agent. On self-host, add `--url https://api.yourdomain.com`.

To configure an MCP host by hand, see the [MCP server](/mcp/introduction) page.

## 3. Connect a source

Open **Settings → Integrations** and connect a CRM, mailbox, call recorder or outbound tool. Each provider has a setup page under [Providers](/providers/overview).

## 4. Ask for an account

Ask your agent about an account, or call the API:

```bash
curl -X POST https://api.opennous.cloud/v2/context \
  -H "Authorization: Bearer $NOUS_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{ "focus": "acme.com" }'
```
