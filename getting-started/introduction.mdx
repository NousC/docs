## What is Nous?

Nous is **GTM data infrastructure for agents** — one identity-resolved record per human, every channel merged, queryable in a single MCP call.

- **Unify** Apollo, Salesforce, Smartlead, Gmail, and LinkedIn into one record per person
- **Agent-ready** — full account context returned in one MCP call
- **Live sync** — outbound, comms, and CRM stay in lockstep
- **Self-host or cloud** — AGPL v3 binary you run anywhere, or use the hosted version
