## What is Nous?

Nous is **the context layer GTM agents run on**. It unifies your GTM stack — Apollo, Salesforce, Smartlead, Gmail, LinkedIn — into one identity-resolved account record, and returns it to an agent in a single MCP call.

- **One account record** — every contact, channel, and touch at an account, merged and deduplicated into a single source of truth
- **Agent-ready** — the full account returned in one MCP call: structured context, not a raw data dump
- **Live sync** — outbound tools, comms, and CRM stay in lockstep, bi-directionally
- **Open by default** — AGPL v3, self-host free forever, or skip the setup with Nous Cloud
